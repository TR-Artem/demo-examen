## Что реализовано

### Модуль 1 — БД (10 баллов)

- 10 таблиц в 3НФ: `roles`, `users`, `categories`, `manufacturers`,
  `suppliers`, `units`, `pickup_points`, `order_statuses`, `products`, `orders`.
- PK/FK, `UNIQUE` на артикул, `CHECK` на цену, остаток и скидку.
- `schema.sql` с DDL и демо-данными; `PRAGMA foreign_keys = ON`.
- ER-диаграмма: `../materials/ER_диаграмма_programmer.md`.

### Модуль 2 — алгоритм и каталог (15 баллов)

- Окно входа: логин/пароль из БД или «Гость».
- ФИО и роль в правом верхнем углу, выход.
- Список товаров: артикул, наименование, категория, производитель,
  поставщик, цена, единица, остаток, скидка, наличие фото.
- Заглушка «нет» вместо отсутствующего фото.
- Цвета: скидка больше 15% — фон `#2E8B57`; остаток 0 — голубой;
  при скидке цена показана как «старая → новая».
- Блок-схема: `../materials/Блок-схема_programmer.md`.

### Модуль 3 — поиск, фильтр, CRUD товара (25 баллов)

- Поиск по наименованию, описанию, производителю и поставщику.
- Сортировка по остатку ↑/↓.
- Фильтр по поставщику, первый пункт «Все поставщики».
- Всё работает одновременно и в реальном времени.
- Форма товара: все поля, выпадающие списки, фото, цена/количество/скидка.
- ID нового товара = `MAX(product_id) + 1`, при редактировании только чтение.
- Одно окно редактирования товара.
- Удаление товара; товар из заказа удалить нельзя.
- После изменений список обновляется.

### Модуль 4 — заказы (25 баллов)

- Кнопка «Заказы» у менеджера и администратора.
- Список заказов: номер, артикул, статус, пункт выдачи, даты.
- Форма заказа: товар, статус, пункт выдачи, дата заказа, дата выдачи.
- Добавление, редактирование и удаление — только администратор.
- После изменений список обновляется.

## Проверка

```bash
python -m py_compile app.py
python app.py
```

Проверь сценарии:

1. `admin` → каталог → добавить товар → изменить → удалить товар без заказа.
2. Попробовать удалить товар из заказа — должно быть запрещено.
3. `manager` → видны поиск, фильтр, сортировка и «Заказы», но нет CRUD.
4. «Гость» → только просмотр каталога без фильтров.
5. Поиск + фильтр + сортировка одновременно.
6. Скидка больше 15% и товар с остатком 0 — проверить цвета.

> Фото товара хранится путём. Для точного требования «300×200» можно
> подключить Pillow и ресайзить изображение при сохранении.
