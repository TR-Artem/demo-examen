# Дизайн, адаптив 390×844, слайдер, анимации

## Дизайн-система

```css
:root {
  --brand: #2563eb;
  --brand-dark: #1e40af;
  --accent: #f59e0b;
  --bg: #f8fafc;
  --card: #ffffff;
  --ink: #0f172a;
  --muted: #64748b;
  --line: #e2e8f0;
  --danger: #dc2626;
  --radius: 16px;
}
```

- 1 основной цвет, 1 акцент, нейтральные;
- шрифт `system-ui` или один подключённый;
- размеры 14/16/20/28/36;
- отступы 4/8/12/16/24/32;
- радиусы и тени единые.

## Компоненты

- кнопка: primary / ghost / danger;
- поле: обычное / focus / error / disabled;
- карточка курса;
- бейдж статуса;
- alert success/error/warning;
- пагинация;
- пустое состояние.

## Мобильная версия 390×844

```css
.container { width: min(100% - 32px, 1120px); margin-inline: auto; }

@media (min-width: 640px) { .grid { grid-template-columns: repeat(2, 1fr); } }
@media (min-width: 960px) { .grid { grid-template-columns: repeat(3, 1fr); } }
```

Проверь:

- меню-гамбургер;
- формы не вылезают;
- таблица админки превращается в карточки;
- слайдер не выше экрана;
- зоны нажатия ≥ 44 px;
- шрифт полей ≥ 16 px.

## Слайдер

```html
<div class="slider" data-slider>
  <img class="slider__img" src="/static/img/slide-1.svg" alt="Слайд 1">
  <button data-prev aria-label="Назад">‹</button>
  <button data-next aria-label="Вперёд">›</button>
  <div class="slider__dots"></div>
</div>
```

Требования: 4 изображения одного размера, 3 секунды, кнопки, пауза
при наведении.

## Анимации

```css
.card { transition: transform .2s ease, box-shadow .2s ease; }
.card:hover { transform: translateY(-4px); box-shadow: 0 12px 30px rgba(15,23,42,.12); }

@keyframes fade-up {
  from { opacity: 0; transform: translateY(12px); }
  to   { opacity: 1; transform: translateY(0); }
}
.reveal { animation: fade-up .5s ease both; }

@media (prefers-reduced-motion: reduce) {
  * { animation-duration: .001ms !important; transition-duration: .001ms !important; }
}
```

## Доступность

- `alt` у изображений;
- `aria-label` у иконок-кнопок;
- `aria-expanded` у меню;
- `aria-invalid` у полей с ошибкой;
- `focus-visible` не отключать;
- контраст ≥ 4.5:1;
- skip-link в начале страницы.
