## 8 таблиц «Чудо Обувь»

`roles → users → orders → order_items ← product_items ← products / sizes`
`categories → products`

- `product_items` = модель + размер + остаток, `UNIQUE(product_id,size_id)`
- `order_items` = количество + **цена за единицу**
- итог заказа **не хранится**: `SUM(quantity * unit_price)`
- `PRAGMA foreign_keys = ON`
- `ON DELETE CASCADE` у строк заказа, `RESTRICT` у заказанной позиции

## SQL-минимум

```sql
-- остаток и «много/мало»
SUM(pi.quantity) > 5 → 'много' ELSE 'мало'

-- скидка 25%
ROUND(p.price * CASE WHEN NOT EXISTS (
  SELECT 1 FROM orders o
  JOIN order_items oi ON oi.order_id=o.order_id
  JOIN product_items x ON x.item_id=oi.item_id
  WHERE x.product_id=p.product_id
    AND o.order_date >= date('now','start of month','-1 month')
    AND o.order_date <  date('now','start of month')
) THEN 0.75 ELSE 1 END, 2)

-- итог заказа
SUM(oi.quantity * oi.unit_price)

-- статистика
COUNT(*), SUM(total), ROUND(SUM(total)/COUNT(*), 2)
```
