## Схема

```
roles 1—M users 1—M orders 1—M order_items M—1 product_items
categories 1—M products 1—M product_items M—1 sizes
```

| Таблица | PK | FK | Смысл |
|---|---|---|---|
| `roles` | `role_id` | — | Администратор / Менеджер / Пользователь |
| `categories` | `category_id` | — | Детская / Женская / Мужская |
| `sizes` | `size_id` | — | 35 размеров (18–45) |
| `users` | `user_id` | `role_id` | логин, ФИО (пароля нет) |
| `products` | `product_id` | `category_id` | модель, цена, фото, состав |
| `product_items` | `item_id` | `product_id`, `size_id` | остаток по размеру |
| `orders` | `order_id` | `user_id` | дата заказа |
| `order_items` | `order_item_id` | `order_id`, `item_id` | количество, цена за единицу |

## 3НФ за 5 минут

| Форма | Проверка | В «Чудо Обувь» |
|---|---|---|
| 1НФ | В ячейке одно значение | размеры не строкой «36,37,38», а таблица `sizes` |
| 2НФ | Зависимость от всего ключа | в `product_items` остаток зависит от пары «товар+размер» |
| 3НФ | Нет транзитивных зависимостей | название категории не дублируется в товаре |

**Каждый факт — в одном месте.** Итог заказа не хранится: он считается из
`order_items`.

## Ограничения, которые проверяет эксперт

```sql
product_items:
  UNIQUE (product_id, size_id)
  CHECK (quantity >= 0)
  FK product_id → products ON DELETE CASCADE
  FK size_id    → sizes    ON DELETE RESTRICT

order_items:
  CHECK (quantity > 0)
  CHECK (unit_price >= 0)
  FK order_id → orders        ON DELETE CASCADE
  FK item_id  → product_items ON DELETE RESTRICT
```

`CASCADE` у строк заказа: удалили заказ — ушли его строки.
`RESTRICT` у позиции: нельзя удалить то, что уже заказано.
В SQLite обязательно `PRAGMA foreign_keys = ON`.

## Блок-схемы к Заданию 2 (ГОСТ 19.701-90)

Нужны **два алгоритма**: оформление заказа и расчёт цены со скидкой.

**Цена:**

```
(Начало) → [Взять цену товара]
   → <Есть заказы товара в прошлом месяце?>
        Да  → [Цена без скидки] ─────────┐
        Нет → [Цена × 0,75] → [Округлить] ┤
   → (Конец) ◄────────────────────────────┘
```

**Заказ:**

```
(Начало) → [Вход по логину] → <Логин найден?>
   Нет → [Сообщение об ошибке] → (Начало входа)
   Да  → [Каталог] → [Карточка товара] → [Размер и количество]
        → [В корзину] → <Подтвердить заказ?>
             Нет → [Каталог]
             Да  → <Остаток достаточен?>
                     Нет → [Сообщение] → [Карточка]
                     Да  → [Создать заказ] → [Списать остаток]
                          → [Обновить каталог] → (Конец)
```

Символы: овал — начало/конец, прямоугольник — процесс, ромб — решение
(«Да»/«Нет»), параллелограмм — ввод/вывод, стрелки — поток.

Снимают баллы: нет «Начало/Конец», ромб без подписей, нет алгоритма скидки,
файл не PDF.
