# Карта «5 из 5»: что освоить и где это тренировать

Цель «5» = **90+ из 100**. Значит, нельзя пропустить целое задание:
75 баллов лежат в Заданиях 3–5, но и 15 баллов Задания 1 терять нельзя.

## Недели и результат

| Неделя | Что должно быть готово | Проверка |
|---|---|---|
| 1–3 | Python: переменные, условия, циклы, списки, словари, функции, файлы, исключения | пишу калькулятор скидки и читаю CSV без подсказок |
| 4–5 | SQL: SELECT, JOIN, GROUP BY, CASE, даты, подзапросы | в тренажёре решены задания 1–14 |
| 6–7 | БД: 8 таблиц, 3НФ, ER, DDL, импорт | `lab/schema.sql` запускается, ER.pdf готов |
| 8 | tkinter: экраны, Treeview, события, сообщения | могу собрать окно с таблицей и поиском |
| 9 | Задание 2: каталог, «много/мало», подсветка, скидка 25% | каталог показывает скидку и подсветку |
| 10 | Задание 3: вход, фильтры, карточка, корзина, заказ | заказ создаётся, остаток списывается |
| 11 | Задания 4–5: заказы, состав, статистика, руководство, git | все 5 заданий работают в одном приложении |
| 12 | Пробники 1:30 / 2:30 / 4:00 | ≥90% в чек-листе, все артефакты в git |

## Definition of Done для «5»

- [ ] Все 5 заданий работают в **одном** приложении.
- [ ] Все 38 пунктов чек-листа в тренажёре закрыты.
- [ ] Пробник ≥ 90% **с таймером 4:00**.
- [ ] 7 артефактов в git: `schema.sql`, `ER.pdf`, `flowchart.pdf`,
      исходники папкой, `README.md`, `Руководство_пользователя.docx`,
      скриншоты.
- [ ] Приложение запускается на чистой машине по инструкции.
- [ ] Нет аварийных завершений ни в одном сценарии.
