# Чудо Обувь — система оформления заказов

Учебный проект по КИМ **09.02.07-2-2027** (квалификация «Программист»,
профильный уровень). Предметная область: торговая компания «Чудо Обувь».

## Стек

Python 3.10+, tkinter, SQLite.

## Запуск

```bash
python example_app.py
python example_app.py --reset    # пересоздать базу
python import_csv.py             # импорт файлов import
```

## Аккаунты

Пароль не требуется — вход по логину:

| Логин | Роль |
|---|---|
| `admin` | Администратор |
| `manager` | Менеджер |
| `asidorova` | Авторизованный пользователь |
| «Без входа» | Гость |

## Функциональность

- каталог: изображение/заглушка, категория, наименование, производство,
  состав, цена со скидкой;
- «много/мало» по суммарному остатку, подсветка остатка ≤ 3;
- скидка 25% товарам без заказов в прошлом календарном месяце;
- поиск по наименованию и описанию, фильтр по категории,
  сортировка по цене — в реальном времени;
- карточка товара: размерный ряд и доступные размеры;
- корзина и оформление заказа со списанием остатка;
- заказы и состав заказа для Менеджера и Администратора;
- статистика: количество заказов, выручка, средний чек.
