# «Корочки.есть» — портал онлайн-курсов

Учебный проект к демонстрационному экзамену **09.02.07**
«Разработчик веб и мультимедийных приложений».

## Стек

- Python 3.10+
- Flask
- SQLite
- Jinja2
- HTML5, CSS3, JavaScript

## Запуск

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Открой <http://127.0.0.1:5000>.

## Функционал

- регистрация с валидацией и уникальным логином;
- вход/выход, сессии, роли;
- создание заявки: курс, дата `ДД.ММ.ГГГГ`, оплата;
- личный кабинет и статусы заявок;
- отзыв только после завершения курса;
- админ-панель: фильтр, поиск, сортировка, пагинация;
- смена статусов, отмена с причиной;
- адаптив 390×844, слайдер 4 изображения / 3 секунды, анимации;
- JSON API `/api/applications` и `/api/admin/applications`.

## Структура

```
app.py            маршруты
db.py             подключение к SQLite
models.py         dataclass-модели и репозитории
security.py       валидация, CSRF, пароли, роли
seed.py           демо-данные
schema.sql        DDL
templates/        Jinja2
static/           CSS, JS, изображения
tests/            smoke-тесты
```

## База данных

6 таблиц: `roles`, `users`, `courses`, `application_statuses`,
`applications`, `reviews`. Связи 1:M, ограничения UNIQUE/CHECK/FK,
индексы по заявкам и рейтингу.

## Скриншоты

6. Админ-панель.
