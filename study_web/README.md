# ДЭ.Курс — учебный портал

Веб-оболочка для подготовки к демонстрационному экзамену 09.02.07.
Никаких заявок, цен, каталога и админки. Только:

1. вход или регистрация (никнейм + пароль + повтор);
2. выбор курса из списка;
3. сам курс в стиле Stepik: слева содержание курса, справа текущий шаг.
   Порядок теорий и задач сохранён: уроки идут l01→l15, SQL-задачи s01→s19,
   практика вставлена после соответствующей теории. В конце модуля/курса — тест.

## Запуск

```bash
cd study_web
./run.sh          # macOS / Linux
run.bat           # Windows
```

Открой <http://127.0.0.1:5000>.

Демо-аккаунт: `student` / `password123`.

## Курсы

| Курс | Код | Что внутри |
|---|---|---|
| Веб и мультимедиа | 09.02.07-3 | `../DemoExam-mobile.html` |
| Программист | 09.02.07-2 | `../DemoExam-mobile-programmer.html` |

Курс разбит на модули. Внутри модуля шаги идут в исходной хронологии:

- теория (урок l01, l02, ...);
- практика по этой теме (вопросы или SQL-задачи s01, s02, ...);
- следующая теория и практика;
- в конце модуля/курса — тест (10 вопросов, порог 70%).

Слева — содержание курса со всеми шагами и прогрессом, справа — текущий шаг.
Прогресс по шагам сохраняется в БД. SQL-запросы проверяются на встроенной
SQLite. Полный офлайн-тренажёр доступен отдельной ссылкой из курса.

## Аккаунты

- регистрация: никнейм (буквы, цифры, `_`, от 3 символов), пароль (8+),
  повтор пароля;
- пароль хранится только как хеш Werkzeug;
- после входа открывается список курсов;
- выход — в правом верхнем углу.

## Структура

```
study_web/
  app.py            маршруты: вход, курсы, модули, шаги
  study_content.py  Stepik-структура: модули и шаги
  sql_practice.py   проверка SQL на SQLite
  db.py             SQLite
  models.py         пользователи
  security.py       валидация, CSRF, пароли
  schema.sql        users
  seed.py           демо-аккаунт student
  templates/        base, login, register, courses, course, error
  static/style.css  минимальный интерфейс
  tests/test_app.py тесты
```

## Маршруты

| Метод | URL | Назначение |
|---|---|---|
| GET | `/` | вход или список курсов |
| GET/POST | `/register` | регистрация |
| GET/POST | `/login` | вход |
| POST | `/logout` | выход |
| GET | `/courses` | список курсов |
| GET | `/course/<slug>` | первый непройденный шаг |
| GET | `/course/<slug>/module/<n>` | первый шаг модуля |
| GET/POST | `/course/<slug>/module/<n>/step/<s>` | теория, практика, тест |
| GET | `/course/<slug>/content` | полный офлайн-тренажёр |

## Проверка

```bash
python -m unittest discover -s tests -v
```
