# Мобильная версия тренажёра

Файлы лежат в корне проекта. **Актуальная версия — HTML**; APK собран из старой версии «Программист» и оставлен как архив.

| Файл | Что это |
|---|---|
| **`DemoExam-09-02-07.apk`** | Архив: APK старой версии «Программист» |
| **`DemoExam-mobile.html`** | Веб-курс одним HTML-файлом (~1 МБ) |
| **`DemoExam-mobile-programmer.html`** | Курс «Программист» одним HTML-файлом (~1 МБ) |

Оба **полностью офлайн**: интернет, аккаунт, сервер и разрешения не нужны.
Движок SQLite (sql.js, WebAssembly) встроен внутрь, поэтому SQL-задачи
проверяются прямо на телефоне.

## Вариант 1. Установить APK (архив)

1. Скопируй `DemoExam-09-02-07.apk` на телефон: кабелем, в Telegram «себе»,
   через Google Drive / локальную сеть — как удобно.
2. Открой файл в приложении «Файлы» / «Загрузки» → **Установить**.
3. Если Android спросит — разреши **«Установку из неизвестных источников»**
   для того приложения, откуда открываешь файл (на Android 8+ разрешение
   выдаётся конкретному источнику, а не глобально).
4. Предупреждение «Приложение от неизвестного разработчика» — нормально:
   APK подписан самоподписанным сертификатом `CN=DemoExam Trainer`.
   Нажми **«Всё равно установить»**.
5. Ярлык называется **«ДЭ 09.02.07 — Тренажёр»** (зелёная иконка `{ / }`).

**Требования:** Android 5.0+ (minSdk 21), рекомендуется Android 7.0+ с обновлённым
*Android System WebView* — он нужен для WebAssembly.targetSdk = 34 (Android 14).
Разрешений в манифесте нет вообще: ни INTERNET, ни хранилища, ни камеры.

### Если установка не идёт

| Проблема | Что сделать |
|---|---|
| «Приложение не установлено» | Свободное место, отключи «Play Protect» на время установки или подтвердите «Всё равно установить» |
| «Файл повреждён» | Перекачайте APK заново (не открывайте его почтовым вложением «на лету») |
| Белый экран | Обновите *Android System WebView* и *Chrome* в Play Market, перезапустите приложение |
| Кнопка «Назад» закрывает приложение | Это нормально: внутри приложения «Назад» листает историю WebView, затем выходит |

## Вариант 2. Просто открыть HTML

Скопируй `DemoExam-mobile.html` на телефон и открой в Chrome (или любом
современном браузере). Это **один файл** — данные, стили, скрипты и SQLite
уже вшиты в него, соседние файлы не нужны. Удобно, если APK ставить нельзя.

Можно добавить на главный экран: Chrome → ⋮ → «Добавить на главный экран».

## Что умеет

| Раздел | |
|---|---|
| 📅 План | 60 занятий на 12 недель, группировка по неделям, галочки, прогресс |
| 📖 Теория | 15 уроков по веб-разработке, отметь «прочитано» |

| 🎓 Пробник | чек-лист по критериям КОД 09.02.07-3-2026 на **100 баллов**, таймер 4:00:00, оценка 3/4/5, история |
| 📋 Шпаргалки | 9 готовых кусков кода, копирование в буфер |
| 📈 Прогресс | Готовность в %, слабые темы, история пробников, советы, экспорт/импорт прогресса |

Плюс 🌙 тёмная тема, оформление в стиле курса Stepik (тёмная шапка, боковое
содержание, кнопка «Следующий шаг»), крупные сенсорные кнопки и адаптация под
узкий экран. Всё сохраняется в `localStorage` и не стирается при перезапуске.

### Перенос прогресса

На вкладке **«Прогресс»**:
- **«Скопировать JSON»** — положить текущее состояние в буфер;
- **«Вставить JSON»** — вставить скопированный текст и восстановить.

Формат тот же, что у `progress.json` от ПК-версии (`trainer.py`): ключи
`plan_done`, `theory_read`, `quiz`, `sql_done`, `exam_checks`,
`exam_attempts`, `thresholds`. Можно скопировать содержимое `progress.json`
в поле импорта — и продолжить на телефоне с того же места, и наоборот.

> Прогресс APK и отдельного HTML хранится **независимо** (разные origin),
> поэтому между ними его нужно переносить кнопками выше.

## Как устроено / пересборка

| Файл | |
|---|---|
| `assets/index.html` | Исходник мобильной версии (данные подключаются отдельными файлами) |
| `assets/data.js` | Все данные, сгенерированы из `trainer.py` |
| `assets/wasm_data.js` | SQLite-движок (sql-wasm.wasm) в base64 |
| `assets/sql-wasm.js` | Обвязка sql.js |
| `build_apk.py` | Полный цикл сборки APK |
| `apk_download.py`, `apk_unpack.py` | Скачивают/распаковывают портативный инструментарий |
| `MainActivity.java` (генерируется) | WebView-обёртка: JS, DOM Storage, загрузка `file:///android_asset/index.html` |

В APK кладётся **самодостаточный `index.html`** (все скрипты вшиты в один
файл). Это сделано специально: на Android 11+ WebView может блокировать
загрузку соседних `file://`‑скриптов, а один файл грузится всегда.

Чтобы пересобрать после правок:

```bat
python apk_download.py     :: один раз, ~165 МБ в Temp\opencode\apkbuild
python apk_unpack.py       :: один раз
python build_apk.py        :: собирает APK + DemoExam-mobile.html
```

Инструментарий портативный (JRE 17, Android build-tools r34, android.jar,
ecj, aapt2, d8, zipalign, apksigner) — системные Java/Android Studio не нужны.
Готовый APK подписывается схемами **v1 + v2**, проверено `apksigner verify`.

> Если поменяешь задания в `trainer.py`, просто запусти `build_apk.py` —
> `data.js`, standalone-HTML и APK обновятся автоматически.
