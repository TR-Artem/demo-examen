# ДЭ-2027 «Разработчик веб и мультимедийных приложений»
## Курс подготовки к демонстрационному экзамену 09.02.07

Комплект для **ГИА, профильный уровень**, квалификация
**«Разработчик веб и мультимедийных приложений»** (специальность 09.02.07
«Информационные системы и программирование»).

Основа курса — **КОД 09.02.07-3-2026** (последний завершённый экзамен):
3 модуля, 4 часа, 75 баллов инвариант + 25 вариативная часть.
Стек: **Python + Flask + SQLite + HTML/CSS/JavaScript**.

> веб-квалификации в открытом доступе не подтверждена. Колледжи уже

## Три курса в одном тренажёре

| Курс | Шифр | Содержание | Запуск |
|---|---|---|---|
| **Веб и мультимедиа** | 09.02.07-3-2027 | Flask + SQLite + HTML/CSS/JS, 3 модуля | `python trainer.py` или `./run.sh` |
| **Программист** | 09.02.07-2-2027 | Python + SQLite + tkinter, 4 модуля, магазин обуви (КОД 2026) | `./run.sh programmer` или `run_programmer.bat` |
| **Информационные системы** | 09.02.07-5-2027 | ER, SQL, авторизация, API, Postman, документы (КИМ 2027) | `./run.sh is` или `run_is.bat` |

В шапке тренажёра есть выпадающий список **«Курс»** — переключение
перезапускает приложение с выбранным содержанием. Прогресс каждого курса
хранится отдельно: `progress_web.json` и `progress_programmer.json`.

Содержание лежит в `course2027.py` (веб), `course_programmer.py` (программист)
и `course_is.py` (информационные системы), реестр — в `courses.py`.

Учебный портал: `study_web/`. Эталонные экзаменационные приложения:
`lab_web/` — для веб-курса, `lab_programmer/` — для «Программиста».

## Быстрый старт

### 1. Тренажёр (Windows / macOS / Linux)

```bash
python trainer.py
```

Нужен только Python 3.10+. `tkinter` и `sqlite3` входят в Python.

### 2. Учебный веб-портал

```bash
cd study_web
./run.sh          # macOS/Linux
run.bat           # Windows
```

Открой <http://127.0.0.1:5000>: вход → выбор курса → модули.
Внутри модуля: теория → практика → теория → практика → тест по модулю.

Демо-аккаунт: `student` / `password123`.

## С нуля до 5: как идти

1. **Не пропускай недели 1–4.** Без HTML/CSS/JS и git веб-экзамен
   превращается в импровизацию.
2. **Собери один каркас** (`lab_web/`) и доведи до автоматизма:
   регистрация → вход → заявка → статус → отзыв → админка.
3. **SQL решай руками** в тренажёре: 19 задач покрывают выборки, JOIN,
   агрегаты, даты и подзапросы.
4. **Раз в неделю — пробник с таймером.** Смотри, какие критерии не закрыты.
5. **Коммить после каждого сценария.** Недосданный файл = 0 баллов
   за критерий.
6. **Модуль 2 не откладывай:** адаптив, слайдер и анимации — это 25 баллов.

### Если на площадке другой стек

КОД разрешает любой полный стек. Если колледж требует PHP/MySQL,
Node.js или Django — меняй только серверную часть и шаблоны;
структура сценария, БД, критерии и чек-лист остаются теми же.
