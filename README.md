## Быстрый старт

1. Установи **Python 3.10+** с https://www.python.org/downloads/
   (галочка **Add Python to PATH**).
2. Двойной клик по **`run.bat`** → откроется тренажёр.
3. Начни с **«План на 12 недель»** → **«Теория»** → **«SQL-практика»**.
4. Готовое приложение: **`run_example.bat`** (или `cd lab` → `python example_app.py`).
5. С телефона: сайт **https://alessstft.github.io/Demoexam/** —
   там две версии: «Веб-версия» и «Скачать APK».

Ничего доустанавливать не нужно: `tkinter` и `sqlite3` входят в Python.

### Две версии на сайте

На GitHub Pages лежат обе версии:

- **веб-версия** — открывается сразу по ссылке, работает в любом браузере;
- **Android APK** — кнопка «Скачать APK» сверху страницы.

Инструкция по включению и обновлению — `GITHUB_PAGES.md`.

## Экзамен 2027 (проект КИМ)

| | |
|---|---|
| Заданий | **5** |
| Баллов | **100** (инвариант 75 + вариативная часть 25) |
| Время | **4 ч 00 мин** |
| Задание 1 — БД | 50 мин, **15** |
| Задание 2 — алгоритм + приложение | 40 мин, **10** |
| Задание 3 — интерфейс и заказ | 60 мин, **25** |
| Задание 4 — заказы у персонала | 60 мин, **25** |
| Задание 5 — статистика + руководство | 30 мин, **25** |

Предметная область: **«Чудо Обувь»**, **8 таблиц**: роли, категории, размеры,
пользователи, товары, товарные позиции, заказы, строки заказов.

Ключевые требования:

- **вход только по логину**, пароль не нужен;
- товарная позиция = **модель + размер**, остаток по размерам;
- **«много»** — больше 5 пар суммарно, иначе **«мало»**;
- остаток **≤ 3** — светло-красная подсветка;
- **скидка 25%** товарам, по которым **не было заказов в прошлом календарном
  месяце**;
- Задание 5 — **окно статистики** (количество, выручка, средний чек) и
  **Руководство_пользователя.docx** на 1–2 страницы с 3+ скриншотами;
- в git-репозитории — исходники **папкой**, скрипт БД, README.md, документы.

**Где баллы:** Задания 3, 4 и 5 дают **75 из 100**. Задание 1 (15) — самые
«дешёвые» баллы, его нужно закрывать первым.

**Оценки:** «4» ≈ 70 %, **«5» ≈ 90 % (90+ из 100)**. Пороги настраиваются
в тренажёре. Шкалу уточни у куратора.

## С нуля до 5: как идти

1. **Не пропускай недели 1–3.** Без Python циклы и словари будут тормозить всё.
2. **SQL решай руками** в тренажёре, не подглядывая в эталон сразу. 19 задач
   покрывают все запросы экзамена.
3. **Собери один каркас** (`lab/example_app.py`) и доведи до автоматизма:
   вход → каталог → карточка → корзина → заказ → заказы → статистика.
4. **Раз в неделю — пробник с таймером.** Смотри, какие критерии не закрыты.
5. **За 5–10 минут до конца задания** — сохранить и залить в git. Недосданный
   файл = 0 баллов за критерий.
6. **Задание 5 не откладывай**: статистика — 25 баллов, руководство — ещё
   часть этих баллов. Шаблон уже лежит в `materials/`.

### Если на площадке MS SQL Server

КИМ говорит «в выбранной СУБД», но в примерах 2027 используется MS SQL Server /
LocalDB. Уточни у куратора. Если SQL Server — открой
`cheatsheets/08_sql_server.md`: там отличия синтаксиса, схема, `pyodbc`,
скидка и статистика в T-SQL.
