# Сайт на GitHub Pages: две версии (веб + APK)

Сайт уже работает: **https://alessstft.github.io/Demoexam/**

GitHub Pages раздаёт ветку `main` (корень). Поэтому на главной лежит
`index.html` — страница с двумя кнопками:

| Версия | Куда ведёт |
|---|---|
| **Веб-версия** | `docs/` — полный тренажёр в браузере |
| **Android APK** | `DemoExam-09-02-07.apk` — скачивание и установка |

Обе версии используют одни и те же материалы: план, теория, тесты,
SQL-практика, пробник. Прогресс хранится локально (`localStorage` или
приложение) и переносится через «Прогресс → Скопировать JSON».

## Что лежит в репозитории

| Файл | Что это |
|---|---|
| `index.html` | главная страница с двумя версиями |
| `.nojekyll` | отключает Jekyll (иначе он может мешать статике) |
| `docs/index.html` | самодостаточный веб-тренажёр (1 МБ, всё внутри) |
| `docs/DemoExam-09-02-07.apk` | APK для скачивания с сайта |
| `publish_site.py` | пересобирает сайт из `DemoExam-mobile.html` |

## Если 404 или старая страница

- подожди 1–2 минуты (Pages пересобирает сайт после пуша);
- открой в инкогнито (кэш);
- проверь **Settings → Pages**: Source = `Deploy from a branch`,
  Branch = `main`, folder = `/ (root)`;
- проверь **Actions** — workflow `pages build and deployment` должен
  завершиться зелёным.

## Как обновить сайт

После изменений в тренажёре:

```bat
python mobile\build_apk.py
python publish_site.py
git add index.html .nojekyll docs publish_site.py
git commit -m "Update website"
git push
```

`publish_site.py`:
1. берёт `DemoExam-mobile.html`;
2. добавляет сверху баннер «Скачать APK»;
3. кладёт в `docs/index.html`;
4. копирует APK в `docs/`;
5. пересобирает главную `index.html` с двумя кнопками.

Через 1–2 минуты сайт обновится.

## Если захочешь отдельный адрес

Можно подключить свой домен: **Settings → Pages → Custom domain**.
Для учебного проекта обычно не нужно.

## Важно

- Репозиторий публичный, сайт тоже публичный. Не клади туда пароли,
  токены и личные данные.
- APK подписан самоподписанным сертификатом — Android предупредит
  «неизвестный разработчик». Это нормально: нажми «Всё равно установить».
- Если позже понадобится вторая учебная версия (например, 2026 и 2027
  на одном сайте) — делается страница `/2026/` и переключатель.
