# Сайт на GitHub Pages: веб-версия + APK

Уже сделано и залито в репозиторий:

- `docs/index.html` — самодостаточный тренажёр (1 МБ, всё внутри, работает
  без интернета после загрузки);
- `docs/DemoExam-09-02-07.apk` — APK для скачивания прямо с сайта;
- `docs/.nojekyll` — чтобы GitHub Pages не обрабатывал файл через Jekyll;
- сверху страницы — полоса **«Веб-версия · Скачать APK для Android · исходники»**.

Осталось **включить Pages** (один раз).

## Включение (3 клика)

1. Открой **https://github.com/alessstft/Demoexam/settings/pages**
2. **Build and deployment → Source**: `Deploy from a branch`.
3. **Branch**: `main`, **folder**: `/docs` → **Save**.
4. Подожди 1–2 минуты и открой:

   **https://alessstft.github.io/Demoexam/**

Готово: на сайте сразу открывается тренажёр, а сверху — кнопка
«Скачать APK для Android». Это и есть две версии: веб и Android.

## Если 404

- подожди 1–2 минуты (первая сборка Pages);
- проверь **Actions** в репозитории — там будет workflow `pages build and deployment`;
- убедись, что выбрано `main` / `/docs`, а не `/root`;
- открой ссылку в режиме инкогнито (кэш).

## Как обновлять сайт

После изменений в тренажёре:

```bat
python mobile\build_apk.py
python publish_site.py
git add docs
git commit -m "Update web version"
git push
```

GitHub Pages пересоберёт сайт автоматически за 1–2 минуты.

`publish_site.py`:
- берёт `DemoExam-mobile.html`;
- добавляет баннер с ссылкой на APK;
- кладёт `docs/index.html`;
- копирует APK в `docs/`.

## Две версии

| Версия | Где | Как пользоваться |
|---|---|---|
| **Веб** | `https://alessstft.github.io/Demoexam/` | открыть в любом браузере, в т.ч. на телефоне |
| **Android** | кнопка «Скачать APK» на сайте или `docs/DemoExam-09-02-07.apk` | скачать и установить |

Обе версии используют один и тот же код и сохраняют прогресс в браузере
(`localStorage`). Прогресс между сайтом и APK можно переносить через
«Прогресс → Скопировать JSON / Вставить JSON».

## Важно

- GitHub Pages у **публичного** репозитория доступен бесплатно и без интернета
  на стороне пользователя (статика). Репозиторий `alessstft/Demoexam` публичный.
- Сайт — публичная страница. Не клади туда личные данные, токены, пароли.
- Если позже захочешь **2026 и 2027** на одном сайте — скажи: сделаю вторую
  страницу `/2026/` и переключатель версий.
